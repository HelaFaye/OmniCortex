OmniCortex review sources

The extension never sends anything about you. A review board is downloaded whole, so it never learns which model you looked at. A Studio is asked about the model on the page, with your Studio's token.

Review boards, one per line: github:owner/repo, owner/repo, or a scoreboard server's URL
Studios, one per line: URL token (the token is optional when Studio runs without one)
Open the Studio once in this browser and accept its certificate if it uses its own. The token is stored in this browser's extension storage; anyone who can use this browser profile can read it.
